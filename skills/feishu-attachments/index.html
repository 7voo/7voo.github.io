飞书发附件

Feishu Attachments

📤 通讯技能 🔥 高频使用 📁 文件操作

📋 技能概述

在飞书消息中发送文件、图片、压缩包等附件给人类。支持多种格式和上传方式， 包括从 URL 上传、本地文件上传、以及 Base64 数据直接发送。

🛠️ 核心工具

1. feishu_doc (文档操作)

用于上传文件/图片到飞书云文档

# 上传图片
action: "upload_image"
doc_token: "ABC123"
url: "https://example.com/image.png"
或 file_path: "/tmp/image.png"
# 上传文件
action: "upload_file"
doc_token: "ABC123"
url: "https://example.com/report.pdf"
或 file_path: "/tmp/report.pdf"

2. message (消息发送)

用于发送消息和附件到飞书聊天

# 发送带附件的消息
action: "send"
channel: "feishu"
message: "这是您要的文件"
filePath: "/tmp/report.pdf"
或 buffer: "base64..."
filename: "report.pdf"

📖 使用场景

📄

发送文档文件

PDF、DOCX、Excel、TXT 等办公文档

🖼️

发送图片

PNG、JPG、GIF、WebP 等图片格式

📦

发送压缩包

ZIP、RAR、7Z 等压缩文件

📊

发送数据报表

自动生成的 CSV、Excel 数据分析报告

💻 实战示例

示例 1: 发送本地文件

# 通过 message 工具发送本地文件

message(
  action: "send",
  channel: "feishu",
  message: "阿宽部长，这是您要的合同审核报告！",
  filePath: "/tmp/contract_review.pdf",
  filename: "合同审核报告 -20260318.pdf"
)

示例 2: 发送网络图片

# 先上传到飞书云文档，再发送

# 步骤 1: 上传图片到云文档
feishu_doc(
  action: "upload_image",
  doc_token: "ABC123",
  url: "https://example.com/chart.png"
)

# 步骤 2: 发送消息（图片会自动显示）
message(
  action: "send",
  channel: "feishu",
  message: "这是最新的数据分析图表！📊"
)

示例 3: 发送 Base64 数据

# 发送生成的二维码/图表等

message(
  action: "send",
  channel: "feishu",
  message: "这是生成的二维码！",
  buffer: "data:image/png;base64,iVBORw0KGgoAAAANS...",
  filename: "qrcode.png"
)

示例 4: 压缩后发送

# 先压缩，再发送

# 步骤 1: 执行压缩命令
exec(
  command: "zip -r /tmp/report.zip /tmp/report_files/"
)

# 步骤 2: 发送压缩包
message(
  action: "send",
  channel: "feishu",
  message: "阿宽部长，完整报告已打包发送！📦",
  filePath: "/tmp/report.zip",
  filename: "完整报告 -20260318.zip"
)

💡 最佳实践

✅

文件命名清晰，包含日期和描述

例：`合同审核报告 -20260318.pdf`

✅

大文件先压缩再发送

减少传输时间，提升用户体验

✅

发送前确认文件路径正确

避免发送失败或空文件

✅

配合文字说明一起发送

告诉用户文件内容和用途

⚠️

注意文件大小限制

飞书单文件限制 500MB，建议控制在 100MB 以内

🔧 常见问题

Q: 发送失败怎么办？

检查：1) 文件路径是否正确；2) 文件是否存在；3) 是否有读取权限； 4) 飞书 Bot 权限是否配置正确（需要 drive:drive 权限）

Q: 图片显示太小？

上传前将图片缩放到 800px+ 宽度，确保在飞书中正常显示。 小图片（如 480x270）会被压缩得更小。

Q: 如何发送多个文件？

方法 1: 打包成 ZIP 发送；方法 2: 分多次 message 调用发送； 方法 3: 上传到飞书云文档后分享链接
